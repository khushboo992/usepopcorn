# 🍿 usePopcorn – Movie Search & Watchlist App

usePopcorn is a modern React application that allows users to search for movies, explore detailed information, rate them, and maintain a personalized watched list with real-time statistics.

🔗 **Live Demo:**  
https://khushboo992.github.io/usepopcorn/

---

## 🚀 Features

- 🔍 Search movies using the OMDb API
- 📄 View detailed movie information (rating, runtime, cast, director, plot)
- ⭐ Rate movies with a custom star rating component
- ➕ Add movies to a personal watched list
- 🗑 Remove movies from the watched list
- 📊 Automatic calculation of:
  - Average IMDb rating
  - Average user rating
  - Average runtime
- ⌨ Close movie details using the Escape key
- ⚡ Responsive and interactive UI
